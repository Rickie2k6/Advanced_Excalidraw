CHATBOT • Cấu trúc mã nguồn

Tài liệu kỹ thuật và kết quả dọn code
Ngày lập: 25/09/2026 • Ngôn ngữ: Tiếng Việt

Dự án cung cấp chatbot cho bảng vẽ Excalidraw. Widget trên trình duyệt gửi câu hỏi và ảnh bảng đến backend FastAPI; backend nhận dạng công thức bằng PaddleOCR-VL, xây dựng ngữ cảnh rồi gọi dịch vụ AI để trả lời. Một pipeline SymPy riêng tạo gợi ý bước giải toán tiếp theo.

Sơ đồ tổng quan

Ứng dụng Excalidraw bên ngoài repository
↓ bridge trên window
Widget JavaScript + CSS
↓ HTTP /api/chat • câu hỏi + ảnh PNG
FastAPI → PaddleOCR-VL → ngữ cảnh bảng
↓ kết hợp công thức từ equations.json
Dịch vụ AI → câu trả lời → Markdown được làm sạch

Luồng phụ: strokes → nhóm công thức → OCR → equations.json → đồ thị quan hệ → frontier → gợi ý. API trạng thái, ảnh và presence phục vụ tích hợp với ứng dụng chủ.

Phạm vi khảo sát

Đọc mã nguồn, cấu hình dependency và điểm đăng ký router trong folder Chatbot. Báo cáo phản ánh cả các file mới chưa được Git theo dõi tại thời điểm khảo sát. Không đọc nội dung .env hoặc đưa dữ liệu người dùng vào báo cáo.

Các mô tả công cụ dựa trên import và lời gọi trong repository, không phải xác nhận phiên bản đang triển khai. Dự án không có ứng dụng Excalidraw chủ hoặc cấu hình build/deploy đầy đủ trong folder này.

Điểm tích hợp

Widget cần window.__excalidrawChatbotBridge do ứng dụng chủ cung cấp. Luồng gửi hiện tại gọi exportWhiteboardToPng(). Module tích hợp còn cung cấp getScene() và exportElementsToPng(). Bare imports và import CSS cần cơ chế bundling/tích hợp từ ứng dụng chủ; widget/package.json chưa có script build thực tế.

03 • Luồng xử lý và dữ liệu

Chat

1. Người dùng gửi câu hỏi qua widget. messages.js lấy bridge, xuất PNG và gửi question cùng whiteboard đến POST /api/chat.

2. chat.py nhận ảnh tùy chọn, chạy analyze_whiteboard trong thread pool và lưu kết quả OCR vào state_store. build_equation_context đọc công thức đã nhận dạng từ equations.json.

3. Nếu request có scene_json, backend tìm ảnh chèn theo fileId, phân tích qua dịch vụ AI và cache kết quả. Widget hiện tại chưa gửi scene_json nên nhánh này chưa được kích hoạt từ luồng gửi tin đang thấy.

4. Backend kết hợp ngữ cảnh và câu hỏi, gọi generate_reply, ghi log rồi trả answer. Widget dùng Marked và DOMPurify để hiển thị.

OCR công thức và gợi ý

strokes/sync lưu nét vẽ và loại công thức mất nét nguồn; equations/group gom vùng; endpoint OCR hoặc sync cập nhật equations.json. whiteboard/hints gọi adapter và reasoning pipeline: graph → frontier → parse → next_step → instruction.

Kết quả xác minh

Đạt: parse cú pháp 47 file Python bằng AST; kiểm tra cú pháp 14 file JavaScript bằng node --input-type=module --check; pip đọc requirement.doc và resolve về 12 dependency, có đủ httpx/openai/sympy.

Không chạy end-to-end: Python đang dùng thiếu FastAPI và PaddleOCR; ứng dụng Excalidraw chủ không có trong folder này. Chưa gọi API AI, chưa tải model hoặc xác minh GPU. Kiểm tra cú pháp không thay thế kiểm thử hành vi.

git diff --check toàn workspace báo vấn đề whitespace ở bốn dòng thuộc các file người dùng đã sửa từ trước: input.js, messages.js và header.js. Các file đó không được chỉnh trong lượt dọn này.

Phần được giữ lại

Giữ toàn bộ dữ liệu và thay đổi có sẵn của người dùng. Giữ API công khai, module export hỗ trợ tích hợp, ảnh mẫu và node_modules vì chưa có bằng chứng đủ mạnh rằng ứng dụng chủ không sử dụng. Không có file dữ liệu nào bị xóa.

Các điểm cần xử lý tiếp

• Đường dẫn ảnh/cache tương đối trong chat.py và openai_service.py có thể lệch với paths.py khi chạy từ backend/. API hints còn dùng đường dẫn tuyệt đối gắn với máy hiện tại.

• config.js và helper IPv4 dùng /chatbot-api, trong khi messages.js gọi /api/chat. Cần xác nhận proxy của ứng dụng chủ trước khi thống nhất URL.

• Hai manifest JavaScript và node_modules đã được Git theo dõi làm tăng trùng lặp. Chưa gỡ vì chưa có cấu hình build của ứng dụng chủ để kiểm chứng.

• Chưa có bộ test ứng dụng hoặc script build widget thực tế. Các điểm trên được ghi nhận, chưa tự ý thay đổi hợp đồng tích hợp trong lượt dọn code này.
